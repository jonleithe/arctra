# EDC active satellite catalog

Snapshot created on **2026-11-13** from the [EUROLAS Data Center (EDC) active satellite list](https://edc.dgfi.tum.de/en/satellites/).

This is the complete 144-entry **active ILRS tracking catalog** at the time of retrieval. It is a reference list, not a claim that every entry is already supported by Arctra: lunar targets have no NORAD ID, restricted targets must not be used operationally, and the current parser deliberately accepts only passive Earth-orbiting CPF v2 files in body-fixed frame 0.

For a future Arctra catalog entry, `CPF key`, `ILRS ID`, and `NORAD ID` are the key fields. The `CPF key` is the lowercase EDC/ILRS filename name. Fresh CPF availability and header validation are still required at run time.
